# Glosario interno de Altanoria (ficticio)

| Término | Significado |
|---|---|
| Espacio | Unidad de trabajo de DocuMind con sus documentos, usuarios y permisos. |
| Ejecución | Una vez que un flujo de AgentHub se lanza de principio a fin; cuenta como una para la facturación. |
| Paso | Cada etapa de un flujo de AgentHub (llamada a un modelo, a una herramienta o a una persona). |
| Puerta | Validación entre dos pasos de un flujo; si falla, el flujo reintenta, escala o se detiene. |
| Conector | Integración de DocuMind con una fuente externa (SharePoint, Confluence, etc.). |
| Crédito SLA | Descuento en la factura por incumplimiento de disponibilidad. |
| Estado de la plataforma | Página pública con incidencias y mantenimientos: estado.altanoria.example. |
| N1 / N2 / N3 | Niveles de soporte: primera línea, especialistas, ingeniería. |
| Cuenta Enterprise | Cliente con contrato a medida y gestor asignado. |

# Objetivos del módulo

*Módulo 05: Roles, personas y comportamiento*

## Objetivos y mapa del módulo

OBJETIVOS DEL MÓDULO

Al finalizar este módulo serás capaz de diseñar prompts de sistema completos que definan con precisión cómo debe comportarse un LLM en cada contexto profesional.

**Explicación**

El objetivo del módulo es poder diseñar prompts de sistema completos que definan con precisión cómo debe comportarse un LLM en cada contexto profesional. Un prompt de sistema es el conjunto de instrucciones estables que fija el comportamiento del asistente durante toda la interacción, a diferencia de las peticiones que el usuario formula en cada turno.

El diseño de un asistente sigue cinco pasos: distinguir **rol** y **persona** (función frente a rasgos comunicativos), definir **responsabilidades** y límites, controlar el **tono** y el **estilo**, adaptar la **profundidad** y probar la consistencia con casos de prueba. Omitir el último es el error más común: un asistente que responde bien a dos pruebas informales puede fallar de forma sistemática ante entradas imprevistas.

# Objetivos del módulo

*Módulo 02: Fundamentos del Prompt Engineering*

## Objetivos de aprendizaje

OBJETIVOS DEL MÓDULO

Al finalizar este módulo, habrás desarrollado las siguientes competencias esenciales para el diseño sistemático de prompts:

1. **Definir Prompt Engineering**: Explicar su utilidad y distinguirlo de la interacción conversacional casual.
2. **Distinguir pregunta vs. especificación**: Reconocer la diferencia entre una consulta informal y el diseño formal de una tarea.
3. **Identificar y aplicar componentes**: Separar con precisión rol, contexto, instrucción, datos, restricciones, formato y criterios.
4. **Detectar y corregir problemas**: Localizar ambigüedades, contradicciones y restricciones ausentes antes de ejecutar el prompt.

> Pregunta de apertura: ¿Qué información necesita un modelo para producir exactamente el resultado que esperamos?

**Explicación**

Al terminar el módulo se debe poder definir **Prompt Engineering** y distinguirlo de una conversación informal, diferenciar una pregunta de una especificación de tarea, identificar los siete componentes de un **prompt** y detectar ambigüedades, contradicciones y **restricciones** ausentes antes de ejecutarlo. Corregir antes de ejecutar ahorra tiempo y evita confiar en una respuesta producida por una **instrucción** defectuosa.

La pregunta de apertura orienta todo el módulo: ¿qué información necesita un modelo para producir exactamente lo que se espera? La respuesta completa incluye objetivo, audiencia, material de partida, límites, formato, criterio de aceptación y tratamiento de lo que falte.

# Objetivos del módulo

*Módulo 03: Tipos funcionales de prompts*

## Objetivos y mapa del módulo

OBJETIVOS DEL MÓDULO

Al finalizar este módulo serás capaz de distinguir los tipos funcionales de prompts, reconocer qué tareas se benefician de cada tipo, combinar funciones cuando sea necesario e identificar los riesgos de una selección incorrecta.

1. **Distinguir tipos**: Identificar las familias funcionales de prompts y sus características diferenciadoras.
2. **Reconocer tareas**: Asociar cada tipo de prompt con las tareas profesionales que mejor lo requieren.
3. **Combinar funciones**: Ordenar varios tipos en un mismo flujo cuando la tarea lo exige.
4. **Gestionar riesgos**: Detectar desajustes entre el tipo elegido y la operación solicitada.

> Ejemplo ilustrativo: Clasificar tareas de extracción, ideación y simulación para identificar el prompt adecuado en cada caso.

**Explicación**

Los cuatro objetivos del módulo son distinguir los **tipos funcionales** de prompts, asociar cada tipo con las tareas que mejor lo requieren, combinar varios tipos en un mismo flujo y detectar desajustes entre el tipo elegido y la operación solicitada. Conocer los tipos permite nombrar la operación que se necesita, y combinarlos permite abordar procesos reales, que casi nunca consisten en una sola operación.

El ejemplo propuesto, clasificar tareas de **extracción**, ideación y **simulación**, muestra que tareas formuladas con palabras parecidas requieren diseños muy distintos: la extracción exige exactitud literal, la ideación variedad y la simulación un personaje consistente.
